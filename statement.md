# Student Planner

## Problem Statement

Students have to manage different academic activities such as subjects, assignments, deadlines, and daily tasks. Keeping track of all these things manually can sometimes lead to missed tasks or unfinished work.

Student Planner is a simple Java-based command-line application that helps students keep their academic work and daily tasks organized in one place. The application allows users to add subjects, assignments, and tasks, set task priorities, mark work as completed, and check their basic productivity.

## Scope

The project focuses on basic academic and daily task management.

The application can be used to:

* Store basic student details
* Add and view subjects
* Add and view assignments
* Mark assignments as completed
* Add and view daily tasks
* Set priorities for tasks
* Mark tasks as completed
* View a basic productivity summary
* Save planner information in a text file
* Load previously saved planner information
* Handle basic invalid inputs

The project is developed as a command-line application using Java. It does not require a database or an internet connection.

## Target Users

The main users of this application are students who want a simple way to keep track of their academic work and daily tasks.

It can be useful for:

* College students
* University students
* Students managing multiple assignments and tasks
* Students who prefer a simple command-line application

## High-Level Features

### Student Profile

The user can enter and view basic information such as name, course, and semester.

### Subject Management

The user can add subjects along with their credit information and view the subjects in the planner.

### Assignment Management

The user can add assignments with the assignment title, subject, and deadline. Completed assignments can be marked as completed.

### Task Management

The user can add daily tasks, enter a date, and assign a priority of High, Medium, or Low. Tasks can also be marked as completed.

### Productivity Summary

The application shows the total number of subjects, assignments, and tasks, along with completed tasks and a basic productivity percentage.

### Save and Load

The user can save planner information to a text file and load the saved information when using the application again.

### Input Validation

The application checks basic user inputs and displays messages when invalid values are entered.
